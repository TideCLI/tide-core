Two ways to use it

Run Tide as a CLI in your existing environment, or boot a dedicated OS with the agent waiting for you on login.

Option 1 — CLI

Tide CLI

A fast terminal coding agent that runs locally on your machine. Works with your existing projects, editors, and shell.

  • Interactive TUI with streaming responses
  • Multi-provider: Claude, ChatGPT, Copilot, Gemini, Cursor, OpenRouter, Perplexity, and more
  • Native tool integration: git, bash, file ops, LSP, Python
  • Session persistence & resume
Install CLI
Option 2 — OS

Tide OS (Live ISO)

A bootable Debian-based live Linux environment with the Tide agent pre-installed and auto-launched on login. Boot from USB, run in a VM.

  • ~1 GB live ISO with UEFI + BIOS boot
  • Auto-login as tide user
  • Bun runtime + agent pre-installed at /opt/tide-os
  • Run the agent just by typing tide
Download ISO

Install the CLI

Currently distributed via source. Binary releases on each tag — check GitHub Releases.

Clone & run with Bun (recommended)
git clone https://github.com/SnoozeScript/tide-os && cd tide-os && bun install && bun run dev
Pre-built Linux binary
curl -fsSL https://github.com/SnoozeScript/tide-os/releases/latest/download/omp-linux-x64 -o omp && chmod +x omp
Bootable live ISO
Download tide-os.iso from GitHub Releases → boot from USB or QEMU
