TIDE is a powerful CLI tool that brings AI-powered coding assistance directly to your terminal. Built with Bun, powered by LLMs, designed for developers.

Install Now → Learn More
tide — bash

Why TIDE?

⚡

Blazing Fast

Built on Bun with Rust-powered native operations. Text processing, grep, and image operations run at native speed.

🖥️

Terminal-First

Beautiful TUI with differential rendering. Stay in your terminal — no context switching to browser-based AI tools.

🔗

Multi-Provider

Use OpenAI, Anthropic, Ollama, Cloudflare Workers AI, and more. Switch between providers seamlessly.

🧠

Context Aware

Understands your codebase. Reads files, runs commands, and maintains project context across sessions.

🔧

Tool Calling

Execute code, run tests, use git, search files, and more. Full tool suite for real-world coding tasks.

📊

Local Observability

Built-in stats dashboard tracks token usage, costs, and performance. Know exactly what you're spending.
