Introduction

The convergence of LLMs and terminal-native development

LLMs have enabled AI-powered code generation, debugging, and reasoning in software development.
Tools like GitHub Copilot, Cursor, and Codeium work only inside graphical IDEs.
Terminal-native developers (Vim, SSH, tmux users) have no equivalent AI assistance.
Tide OS is an AI coding agent for the terminal, also available as a bootable Linux ISO.
02

Problem Statement

Critical gaps in the current AI coding landscape

All AI coding assistants are locked to GUI editors — no terminal-native solution exists.
Existing tools require constant internet — unusable in offline or air-gapped environments.
Source code is sent to cloud servers on every interaction — privacy and IP risk.
No OS ships AI as a core service — it's always an afterthought plugin.

Objectives

What we set out to build

Build a terminal-native AI agent with multi-provider LLM support (Claude, GPT, Gemini, Ollama).

Base Paper

ReAct: Synergizing Reasoning and Acting — Yao et al., ICLR 2023

Proposes interleaving reasoning traces with tool actions in an iterative loop.
Grounding reasoning in real-world feedback reduces hallucination significantly.
Evaluated on HotpotQA, FEVER, ALFWorld, WebShop — outperforms reasoning-only methods.
Tide OS adopts ReAct as its core agent execution loop for autonomous coding tasks.

Thought → Action → Observation — The agent reasons about a task, invokes a tool (file read, bash, grep), observes the result, and iterates until the task is complete.
